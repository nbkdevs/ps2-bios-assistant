PS2 BIOS Checker

Local utility: select a PS2 BIOS file on your PC to calculate MD5, SHA-1, and file size. Nothing is uploaded.

How to test
  1. Click the extension icon in the toolbar.
  2. Click Select BIOS File (or drop a file).
  3. Choose any local file (a real BIOS dump, or any small test file).
  4. Wait for MD5, SHA-1, size, and status to appear.
  5. Optional: paste a hash into Compare to verify a match.

What this checks

MD5, SHA-1, and common dump sizes (2 / 4 / 8 / 16 MiB). A match is reference information only — not proof a file is official, genuine, or legal.

Emulator tip

Place your BIOS dump in the folder your emulator expects (PCSX2, AetherSX2, or NetherSX2), then refresh the BIOS list. Keep the file uncompressed.

Privacy

Files are hashed in this popup only. The extension does not request site access and does not upload BIOS contents.
