# PS2 BIOS Checksum (Hugging Face Space)

Upload a local BIOS dump in the browser UI to calculate MD5, SHA-1, and a basic size check.

This Space does **not** distribute BIOS files. Uploaded bytes are processed in the Space session for hashing only.

## Docs

PS2 BIOS and emulator guides: [https://allps2bios.com/](https://allps2bios.com/)
